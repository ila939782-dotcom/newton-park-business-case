# Методика

## Когортная логика

Для когорты месяца t ожидаемые контракты равны числу лидов × конверсии. При лаге L они учитываются в месяце t+L. Цена закрепляется за исходной когортой. Начального портфеля сделок нет. Контракты, сдвинутые за пределы 12 месяцев, показаны отдельно и не включаются в годовую выручку.

Средняя конверсия взвешивается по лидам: сумма ожидаемых контрактов всех когорт / сумма лидов. В базовых исходных данных это 13,25 / 114 = 11,62%. Эта когортная конверсия отличается от 11 / 114: второй показатель смешивает сформированный спрос с выполненными в текущем горизонте контрактами.

## Прибыль и деньги

- Выручка = выполненные ожидаемые контракты × цена когорты.
- Прямые затраты = выполненные ожидаемые контракты × затраты на один пакет.
- Маржинальный доход = выручка − прямые затраты.
- Операционный результат модели = маржинальный доход − фиксированные расходы.
- Поступления = доля текущей выручки + отложенная часть выручки предыдущих месяцев.
- Чистый денежный поток = поступления − прямые − фиксированные затраты.
- Конечная дебиторская задолженность = накопленная выручка − накопленные поступления.
- Остаток денег = начальные деньги + накопленный денежный поток.

Затраты оплачиваются в месяц возникновения. Начальная дебиторская задолженность равна нулю. Поэтому операционный результат минус изменение дебиторской задолженности должен равняться денежному потоку. Это проверяется тестами во всех сценариях.

Минимальное стартовое финансирование равно максимальному накопленному дефициту при нулевых начальных деньгах. Резерв сверх этого значения не заложен. Внутримесячная последовательность платежей не моделируется, поэтому фактическая пиковая потребность может оказаться выше.

## Безубыточность

Фиксированные расходы / средний маржинальный доход на выполненный контракт. Для закупки и продаж дополнительно показывается округление вверх до целого контракта. При отсутствии контрактов или неположительном маржинальном доходе показатель недоступен, а не равен нулю.

## Ограничения

Нет налогов, амортизации, процентов, курсовых разниц, капитальных затрат, просрочек и кредиторской задолженности. Показатель не называется чистой прибылью или свободным денежным потоком. Дробные контракты сглаживают волатильность маленькой выборки. Сценарии показывают чувствительность, но не доказывают вероятность успеха.

## Excel и Python

Excel содержит одну редактируемую базовую модель с отдельными входами и расчётами. Python применяет одну функцию `evaluate` к каждому набору допущений. CSV сравнения — снимок расчётов. При выпуске портфельной версии ключевые показатели Excel сопоставлены с Python, включая изменённый лаг и стоимость выполнения. Тесты в репозитории выполняются на Python; Excel не требуется для их запуска.
